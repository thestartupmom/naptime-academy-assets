The road

How it went

  1. 1

    I couldn’t describe where it should go

    Every nudge got it close. None of them got it where I pictured it.

    Claude
    Can you move the card higher?
    Moved it up.
    Hmm, more to the left. And tilt it a little.
    Nudged it left and tilted it 4 degrees.
    Closer, but that’s still not it. I can’t figure out how to describe where I want it.
  2. 2

    So I asked to draw it

    You don’t need the right term for it. I just asked.

    Claude
    Can you let me draw on the frame so I can show you exactly where I want this?
    Yes, let’s do that. I’ll give you the still of you on that line.
  3. 3

    It gave me a paused shot of my reel to draw on

    The exact moment from that line. I dragged a box where the graphic goes and set its tilt with the slider. The red bands mark where Instagram’s buttons and caption cover the video, so nothing important lands under them.

    Claude
    Drag a box where you want it (it keeps a 9:16 shape), set the tilt with the slider, and hit send.

    Drag on the still where it should sit. It stays 9:16. The red bands are Instagram’s header and caption zones.

    centre (296, 530) · 415×737 · tilt -6°

    Anything else about it (optional)
    Send placement Clear
  4. 4

    It put it right where I drew it

    My box became exact numbers: where it sits, how big it is, and its angle. First try.

    Claude
    Send placement
    Got it. Center (296, 530), 415 × 737, tilted −6°. Placing it there now.

Can you let me draw on the frame so I can show you exactly where I want this?

Works for anything you need to place: a photo, a card, a sticker, a caption.
